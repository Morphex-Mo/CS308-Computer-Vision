# README Maintenance Guide

本文件用于说明本仓库 README 与相关元信息（如 LICENSE）的维护规范，便于后续持续更新。

## 维护目标

- 保证仓库描述与目录结构一致。
- 保证学术诚信声明长期可见且措辞明确。
- 保证许可证信息与实际授权方式一致。

## 必须保留内容

每次更新 `README.md` 时，以下内容必须保留：

- “本仓库仅供参考，请勿直接抄袭”的明确声明。
- “本仓库为南科大 CS308 计算机视觉课程材料”的定位说明。
- 主要目录结构说明（至少覆盖 `lab/`、`Lectures/`、`lab课分享前沿/`）。
- 许可证入口与说明（指向 `LICENSE`）。
- README 顶部“最后维护日期”（格式建议为 `YYYY-MM-DD`）。

## 更新触发条件

在以下场景中应同步更新 `README.md`：

- 新增或删除实验目录（例如新增 `lab6/`）。
- 讲义目录发生明显变更。
- 前沿分享资料新增独立子模块。
- 授权方式或版权声明调整。

## 推荐更新流程

1. 先确认目录与文件变更范围。
2. 更新 README 的“仓库内容概览”对应条目。
3. 同步更新 README 顶部“最后维护日期”。
4. 复核学术诚信声明是否仍在显著位置。
5. 检查 `LICENSE` 与 README 的许可证描述是否一致。
6. 提交前由至少一名维护者进行快速审阅。
7. 若通过 PR 合并，建议 PR 标题沿用 `docs(...)` 前缀（与提交信息模板保持一致）。

## 文案规范

- 使用简洁、直接、可执行的中文描述。
- 不在 README 中放置具体作业答案。
- 避免对课程政策作超范围解释；以课程官方通知为准。

## 版本记录建议

可在提交信息中采用如下格式：

- `docs(readme): update lab4 summary`
- `docs(license): align with CC BY-NC-SA 4.0`
- `docs(maintenance): refresh update checklist`

## 维护责任建议

- 仓库主要维护者负责最终合并文档变更。
- 贡献者提交资料时，需同步检查 README 是否需要更新。
