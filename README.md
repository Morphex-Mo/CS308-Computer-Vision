# SUSTech CS308 计算机视觉课程材料仓库

本仓库为南方科技大学（SUSTech）CS308 计算机视觉课程相关学习资料与实验记录。

最后维护日期：2026-04-01

## 重要声明（学术诚信）

- 本仓库内容**仅供参考与学习交流**。
- 请勿直接抄袭本仓库中的实验代码、报告内容或作业答案。
- 使用本仓库时请遵守课程学术诚信要求与学校相关规定。
- 若你在此基础上完成课程作业，请务必独立思考、独立实现并自行撰写说明。

## 仓库内容概览

### 1. 作业（Assignment）

- `Assignment/Assignment-1/`
  - `code/`：作业 Notebook 与代码（如 `student_code.py`、`utils.py`、测试 Notebook）。
  - `data/`：作业数据。
  - `results/`：作业结果与额外实验输出。
  - `zip_submission.py`：作业打包脚本。

### 2. 实验（lab）

- `lab/lab1/`：图像读取与保存、基础图像处理工具链。
- `lab/lab2/`：图像形成、投影与变换。
- `lab/lab3/`：图像处理基础实验。
- `lab/lab4/`：频域滤波与离散傅里叶变换（DFT）相关实验。
- `lab/lab5/`：图像特征相关内容。
- `lab/lab6/`：课程后续综合实验与扩展内容。

### 3. 课程讲义（Lectures）

- `Lectures/`：课程 PDF 讲义与课堂资料。

### 4. 前沿分享资料

- `lab课分享前沿/`
  - `link.txt`：外部资料链接记录。
  - `lab2/`：前沿论文与分享材料。

## 使用建议

- 推荐使用 Python 虚拟环境运行 Jupyter Notebook。
- 建议按 `lab1 -> lab6` 的顺序学习，逐步掌握课程知识。
- 对 Notebook 的修改建议另存为个人版本，便于追踪学习过程。
