# SUSTech CS308 计算机视觉课程材料仓库

本仓库为南方科技大学（SUSTech）CS308 计算机视觉课程相关学习资料与实验记录。

最后维护日期：2026-06-08

## 重要声明（学术诚信）

- 本仓库内容**仅供参考与学习交流**。
- 请勿直接抄袭本仓库中的实验代码、报告内容或作业答案。
- 使用本仓库时请遵守课程学术诚信要求与学校相关规定。
- 若你在此基础上完成课程作业，请务必独立思考、独立实现并自行撰写说明。

## 仓库内容概览

### 1. 作业（Assignment）

- `Assignment/Assignment-1/`
  - `code/`：作业 Notebook 与代码（如 `student_code.py`、`utils.py`、测试 Notebook）。
  - `data/`：作业数据。
  - `results/`：作业结果与额外实验输出。
  - `zip_submission.py`：作业打包脚本。

- `Assignment/Assignment-2/`
  - `proj2/`：第二次作业主代码与特征点标注、匹配等子模块。
  - `extra_data/`：补充数据集。
  - `results/`：作业结果与报告。
  - `zip_submission.py`：作业打包脚本。
  
- `Assignment/Assignment-3/`
  - `Assignment3_code/`：第三次作业代码与notebook
  - `crossvalidtion/`：交叉验证相关内容
  - `environment_assignment3.yml`：环境配置文件
  - `Report.md`：作业报告
  
- `Assignment/Assignment-4/`
  - `code/`：第四次作业代码与notebook
  - `environment.yml`：环境配置文件
  - `report.md`：作业报告
  - `zip_submission.py`：作业打包脚本。

### 2. 实验（lab）

- `lab/lab1/`：图像读取与保存、基础图像处理工具链。
- `lab/lab2/`：图像形成、投影与变换。
- `lab/lab3/`：图像处理基础实验。
- `lab/lab4/`：频域滤波与离散傅里叶变换（DFT）相关实验。
- `lab/lab5/`：图像特征相关内容。
- `lab/lab6/`：课程后续综合实验与扩展内容。
- `lab/lab7/`：支持向量机（SVM）等进阶实验。
- `lab/lab8/`：综合实验与数据集应用。
- `lab/lab9/`：目标检测相关实验
- `lab/lab10/`：卷积神经网络(CNN)基础实验
- `lab/lab11/`：实例分割实验
- `lab/lab12/`：Lab12实验内容
- `lab/lab13/`：目标跟踪实验
- `lab/lab14/`：视频对象分割(VOS)实验
- `lab/lab15/`：图像字幕生成与计算方法实验

### 3. 课程讲义（Lectures）

- `Lectures/`：课程 PDF 讲义与课堂资料。（注：当前目录结构中未显示此文件夹，可能已被移除或重命名）

### 4. 期中论文阅读

- `期中论文阅读/`：包含中英文阅读报告LaTeX源码

### 5. 其他维护文档

- `README.md`：本仓库的主要说明文档
- `README_MAINTENANCE.md`：仓库维护指南

## 使用建议

- 推荐使用 Python 虚拟环境运行 Jupyter Notebook。
- 建议按 `lab1 -> lab15` 的顺序学习，逐步掌握课程知识。
- 对 Notebook 的修改建议另存为个人版本，便于追踪学习过程。
- 根据各Assignment目录下的环境配置文件设置相应的conda环境
